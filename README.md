# ADA Hub

직접 만든 앱과 외부 앱의 링크 및 등록 정보를 보관하는 앱 관리 허브입니다.

- 앱 등록: 이름, 제작자, 앱 주소, 소스 저장소, 설명, 출처, 분류
- 개별 수정, 선택한 앱의 출처·분류·보관 상태 일괄 수정
- 검색, 분류, 즐겨찾기, 보관 및 복원
- 이 브라우저의 localStorage에 등록 정보 저장

앱별 **개별 수정 → 코덱으로 앱 수정**에서 로컬 소스 폴더를 연결하면 코덱에 수정 요청을 보내고 파일에 직접 반영할 수 있습니다. 등록 정보 저장은 기존처럼 독립적으로 동작합니다. 계정 간 동기화 및 공동 등록은 지원하지 않습니다.

## 코덱 연동 실행

Windows에서는 상위 폴더의 `Start-ADA.ps1`을 실행하고 `http://127.0.0.1:3002`에 접속합니다. 이 스크립트는 배포 모드와 `ada-entry.html`을 사용합니다. `npm run build` 또는 `pnpm build`는 배포 파일 생성 후 이 진입 파일도 갱신합니다. 일반 Node.js 환경에서는 의존성 설치 후 `npm start` 또는 `pnpm start`로 실행하세요(기본 포트 3000). 코덱 CLI가 PATH에 있어야 하며 `codex login`이 필요합니다. 이 PC에서는 CLI와 ChatGPT 로그인을 확인했습니다.

1. 앱을 등록하거나 기존 앱의 **개별 수정**을 엽니다.
2. 수정 권한이 있는 앱의 로컬 소스 폴더 절대 경로를 입력하고 **소스 연결 저장**을 누릅니다. 저장소 주소만으로는 연결되지 않으며 소스를 먼저 내려받아야 합니다.
3. 요청을 입력하고 **코덱 수정 실행 · 소스 자동 반영**을 누릅니다.
4. 작업 상태, 코덱 응답, 오류를 앱별 수정 이력에서 확인합니다. 창을 닫아도 서버가 실행 중이면 작업은 계속됩니다.

연결 폴더의 파일이 직접 바뀝니다. 개발 서버가 파일 감시를 지원하면 실행 중인 앱에 반영됩니다. **자동 빌드**를 선택하면 코덱 종료 후 연결 폴더의 `build` 스크립트를 실행합니다. 이 옵션에는 `package.json`의 build 스크립트와 npm/pnpm 실행 환경이 필요합니다. 소스 수정이나 빌드가 공개 URL의 배포를 의미하지는 않습니다. 원격 푸시·배포는 구현하지 않았습니다.

서버는 이 PC의 loopback 주소에만 바인딩합니다. 쓰기 요청은 동일 출처와 서버 세션 토큰을 확인합니다. 코덱은 `workspace-write` 모드로 실행하며 승인 질문을 할 수 없는 실행은 실패할 수 있습니다. 실패 시 일부 파일이 변경되었을 수 있으므로 수정 이력과 소스를 확인하세요. 연결 및 작업 이력은 `.ada/state.json`에 저장되고 Git에서 제외됩니다. 동시에 한 작업만 실행하며 서버 재시작 시 진행 중이던 작업은 중단으로 표시합니다. CLI 종료 성공은 모델이 모든 요구사항을 충족했다는 보장이 아니므로 최종 응답의 검증 결과도 확인하세요.

정적 호스팅된 ADA만으로는 이 PC의 CLI를 실행할 수 없습니다. 코덱 기능은 위 로컬 서버에서 사용할 수 있습니다. 기존 등록 정보는 브라우저/출처별 localStorage에 있으므로 다른 주소로 접속하면 목록이 별도로 표시됩니다.

서버 환경 변수: `PORT`(기본 3000), `ADA_CODEX_BIN`(CLI 실행 파일), `ADA_NPM_CLI`(npm-cli.js 또는 pnpm.cjs/mjs 경로), `ADA_DATA_DIR`(서버 데이터 폴더). 운영 모드는 `NODE_ENV=production`으로 실행하며 먼저 build해야 합니다.

## 개발

Node.js와 패키지 관리자로 의존성을 설치한 후 `dev` 스크립트를 실행합니다. `build` 스크립트는 배포용 `dist/`를 생성합니다.

이 체크아웃의 실행 환경에서 확인한 명령:

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
node scripts/prepare-runtime.mjs
node --test tests/bridge.test.mjs
```

기존 게임 화면 컴포넌트는 소스에 남아 있지만 앱 진입점에서는 사용하지 않습니다.
